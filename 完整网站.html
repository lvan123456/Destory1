📚 变量与数据类型

Python中的变量不需要声明类型，可以直接赋值：

# 变量赋值
name = "Alice"
age = 25
height = 1.65
is_student = True

# 打印变量
print(name)      # 输出: Alice
print(age)       # 输出: 25
print(height)    # 输出: 1.65
print(is_student) # 输出: True

🔄 控制流程

Python支持if-else条件语句和for/while循环：

# if-else语句
if age >= 18:
    print("成年人")
else:
    print("未成年人")

# for循环
for i in range(5):
    print(i)  # 输出: 0, 1, 2, 3, 4

# while循环
count = 0
while count < 5:
    print(count)
    count += 1

📝 函数

使用def关键字定义函数：

def greet(name):
    """打招呼函数"""
    return f"Hello, {name}!"

# 调用函数
result = greet("Bob")
print(result)  # 输出: Hello, Bob!

📋 列表与元组

列表是可变的，元组是不可变的：

# 列表
fruits = ["apple", "banana", "cherry"]
fruits.append("orange")  # 添加元素
print(fruits)  # 输出: ['apple', 'banana', 'cherry', 'orange']

# 元组
colors = ("red", "green", "blue")
print(colors[0])  # 输出: red

📖 字典

字典使用键值对存储数据：

# 字典
person = {
    "name": "Alice",
    "age": 25,
    "city": "New York"
}

print(person["name"])  # 输出: Alice
person["age"] = 26    # 修改值

🏛️ 类与对象

Python是面向对象的编程语言：

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def study(self, subject):
        return f"{self.name} is studying {subject}"

# 创建对象
student = Student("Bob", 18)
print(student.study("Math"))  # 输出: Bob is studying Math

📚 什么是费曼学习法？

费曼学习法是著名物理学家理查德·费曼提出的高效学习方法，通过四个简单步骤帮助你真正理解知识：

1️⃣ 选择主题

选择你想学习的概念或主题

2️⃣ 教授给他人

尝试用简单的语言解释这个概念

3️⃣ 找出漏洞

发现自己解释不清楚的地方

4️⃣ 简化知识

回顾和简化你的解释

✨ 核心功能

💡 简化解释

用简单易懂的语言解释复杂概念，就像在教一个小孩子一样。

❓ 测试问题

生成5个问题来测试你对概念的理解程度，帮助你发现知识漏洞。

🎯 学习建议

根据你的解释给出个性化的学习建议，帮助你更有效地学习。
